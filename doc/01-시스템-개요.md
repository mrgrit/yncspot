## 1.1 도약이란?

**도약(ync-jump-spot)** 은 청년의 취업·자립을 하나의 여정으로 설계한 **청년도약 인재양성 부트캠프 통합 운영 시스템**입니다.
대구 남구(영남이공대) 권역을 기반으로, 취업 준비의 부담을 낮춘 **Spot Work**에서 출발해
교육·포트폴리오·취업·사후관리까지 끊김 없이 연결합니다.

> **핵심 아이디어** — "거창한 취업 준비" 대신 **가벼운 단기 일감(Spot Work)** 부터 시작합니다.
> 일을 하며 등급과 보상이 쌓이고, 자연스럽게 교육으로 이어지며, 결국 협약기업 취업까지 도달합니다.

### 성장 여정 한눈에 보기

```
 유입            성장            이수             연결            정착
┌────────┐   ┌────────┐   ┌──────────┐   ┌──────────┐   ┌────────────┐
│ Spot   │ → │ 등급·  │ → │ 3영역     │ → │ 포트폴리오 │ → │ 협약기업    │
│ Work   │   │ 보상   │   │ 동시이수  │   │ ·배지     │   │ 취업·사후관리│
│ (+AI)  │   │        │   │           │   │           │   │            │
└────────┘   └────────┘   └──────────┘   └──────────┘   └────────────┘
```

## 1.2 핵심 개념

### 트랙(Track) — 두 갈래의 성장 경로

| 트랙 | 코드 | 대상 | 목표 |
|---|---|---|---|
| **Try 트랙** | `try_job` | 아직 진로가 불명확하거나 사회 진입이 필요한 청년 | 경험·자신감 축적, 진로 탐색 |
| **Get 트랙** | `get_job` | 취업 목표가 뚜렷한 청년 | 전공 심화, 협약기업 취업 |

- 참여자는 한 트랙에 소속되며, 트랙에 따라 추천 교육·보고서 지표가 달라집니다.
- 취업률 등 성과 지표는 **트랙별로 구분**해 집계합니다(예: Get 트랙 취업률 vs Try 트랙 취업률).

### Spot 등급(Grade) — 활동으로 오르는 신뢰 등급

| 등급 | 승급 조건 | 의미 |
|---|---|---|
| 🥉 **Bronze** | 기본(가입 시) | 입문 |
| 🥈 **Silver** | Spot **5회** 이상 · 평균 평점 **3.8** 이상 | 신뢰 형성 |
| 🥇 **Gold** | Spot **10회** 이상 · 평균 평점 **4.2** 이상 | 우수 |
| 💎 **Platinum** | Spot **20회** 이상 · 평균 평점 **4.5** 이상 | 최상위 |

- 등급이 높을수록 더 좋은 조건의 Spot 일감에 우선 매칭됩니다.
- 등급 승급은 활동 실적에 따라 **자동으로** 계산됩니다.

### 보상 단계 — "첫 성공"을 응원하는 3단계

개인의 **첫 1·2·3번째 Spot 성공**에 단계적 보너스가 지급됩니다.

| 성공 순서 | 보너스 | 취지 |
|---|---|---|
| 1번째 성공 | **교통비 5,000원** | 첫발을 뗀 것을 응원 |
| 2번째 성공 | **일당의 ½** | 다시 온 것을 환영 |
| 3번째 성공 | **일당 전액** | 습관으로 자리잡도록 |
| 4번째 이후 | 보너스 없음(기본 일당만) | 자립 단계로 이행 |

### 3영역 동시이수 — 균형 잡힌 인재상

교육 과정은 여러 영역으로 구성되어 **동시에 이수**합니다.

| 영역 | 코드 | 설명 |
|---|---|---|
| 사회역량 | `social` | 협업·소통·직업기초 |
| 교양 | `liberal` | 시민의식·문해력 등 기초 소양 |
| AI 공통 | `ai_common` | 전 트랙 공통 AI 리터러시 |
| 전공/직무 | `professional` | 트랙별 직무 전문 역량 |

- 과정은 난이도(공통·초급·중급·고급)와 유형(공통·전공·캡스톤)으로도 분류됩니다.
- 이수 요건(출석·성적)을 충족하면 **디지털 배지**가 자동 발급됩니다.

## 1.3 역할(Role)과 권한

시스템은 **4개 역할**로 운영되며, 로그인 시 선택한 역할에 따라 접근 화면과 권한이 결정됩니다.

| 역할 | 진입 경로 | 핵심 권한 | 볼 수 없는 것 |
|---|---|---|---|
| **참여자** (youth) | `/me` | 본인 활동(Spot·학습·채용·포트폴리오·상담) | 다른 참여자 정보 |
| **사업단 운영자** (operator) | `/admin` | 전체 운영·집계·상담 등록·수료생 관리 | — |
| **협약기업** (company) | `/company` | 수료생 **직무 프로필** 검색, 채용 공고 | 참여자의 **상담·사연**(비공개) |
| **시스템 관리자** (admin) | `/admin` | 운영자 권한 + **데이터 입력·계정·권한 관리** | — |

### 개인정보 보호 원칙

- **상담 내역·사연·신청 계기**는 **사업단(운영자·관리자)** 또는 **본인**만 열람할 수 있습니다.
- 협약기업 인재풀에는 **직무 프로필(역량·이수·캡스톤·배지)** 만 노출되며, 상담·사연은 **비공개**입니다.
- 접근 권한은 화면 단위가 아니라 **데이터 항목 단위**로 통제됩니다.

## 1.4 전체 화면 지도

| 경로 | 화면 | 설명 |

## 1.5 데이터는 어디서 오나?

- 시스템의 모든 화면은 **입력된 실데이터**를 기반으로 동작합니다.
- 지표(취업률·양성인원·Spot 누적·만족도 등)는 별도로 관리하지 않고 **원천 데이터에서 실시간 집계**됩니다.
  → 즉, 참여자·교육·Spot·취업 데이터가 정확히 입력되면 대시보드와 보고서는 **자동으로** 정확해집니다.
- 실데이터의 입력·수정·가져오기는 **[05. 관리자 · 데이터 관리](05-관리자-데이터관리.md)** 를 참고하세요.
