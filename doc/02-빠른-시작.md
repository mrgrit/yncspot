## 2.1 접속하기

브라우저에서 시스템 주소로 접속하면 **랜딩 화면**이 나타납니다.

- 내부망(사무실 PC): `http://localhost:5173` 또는 `http://<서버IP>:5173`
- 외부망(현장·모바일): 사업단에서 공유한 **공개 주소**(`https://…`)로 접속합니다. → [2.5 외부 접속](#25-외부-네트워크에서-접속) 참고

랜딩 화면의 **로그인/시작하기** 버튼을 누르면 로그인 화면으로 이동합니다.

---

## 2.2 로그인 & 역할 선택

로그인 화면에서 **본인의 역할**을 선택합니다.

| 선택 | 이동 화면 | 누가 |
|---|---|---|
| **참여자** | `/me` 마이페이지 | 부트캠프 참여 청년 |
| **사업단 운영자** | `/admin` 대시보드 | 사업단 담당자 |
| **협약기업** | `/company` 기업 포털 | 협약기업 채용 담당자 |
| **시스템 관리자** | `/admin` 대시보드 | 데이터·계정 관리자 |

- 로그인 세션은 브라우저에 저장되어, 다시 접속하면 마지막 역할로 자동 진입합니다.
- 역할을 바꾸려면 상단 바에서 **로그아웃** 후 다른 역할로 다시 로그인합니다.
- 권한이 없는 화면에 접근하면 본인 역할의 홈 화면으로 자동 이동됩니다.

> 💡 **계정 로그인** — 운영 환경에서는 역할 선택 대신 **아이디/비밀번호(또는 기관 SSO)** 로 로그인하며,
> 계정에 부여된 역할에 따라 화면이 결정됩니다. 계정 발급·권한 부여는 시스템 관리자가 수행합니다.
> ([05. 관리자 · 데이터 관리](05-관리자-데이터관리.md) 참고)

## 2.3 공통 화면 요소

모든 역할의 화면은 공통 구조를 따릅니다.

### 상단 바 (Topbar)

- **좌측**: 시스템 로고(도약) — 클릭 시 홈으로 이동
- **우측**: 알림(🔔) · 내 프로필 · 로그아웃
- **알림**: 새 Spot 매칭, 수강 승인, 배지 발급, 채용 진행 등 이벤트를 표시합니다.
  종을 눌러 목록을 열고, 개별 또는 **전체 읽음 처리**할 수 있습니다.

### 좌측/하단 내비게이션

- 역할별 주요 메뉴가 고정 표시됩니다.
  - 참여자: **홈 · Spot · 학습 · 채용 · AI**
  - 운영자/관리자: **대시보드 · 참여자 · 교육과정 · Spot Work · 협약기업 · 취업매칭 · 수료생 · 보고서**
- 모바일에서는 하단 탭 형태로, 데스크톱에서는 좌측 사이드바로 나타납니다(반응형).

### 목록·상세 패턴

- 대부분의 목록은 **검색어·필터**를 지원합니다.
- 목록의 **제목·이름을 클릭**하면 상세 정보가 **팝업(다이얼로그)** 으로 열립니다.
  - **사람** 클릭 → 프로필·이수·Spot 이력·(권한 시)상담
  - **교육과정** 클릭 → 커리큘럼·학습성과·개설 분반
  - **포트폴리오/캡스톤** 클릭 → 개요·역할·기술·성과·산출물 링크

---

## 2.4 화면이 잘 안 보일 때

- **표가 잘려 보이면** 표를 좌우로 스크롤하세요(넓은 표는 가로 스크롤됩니다).
- **차트가 안 뜨면** 브라우저를 새로고침하세요.
- 권장 브라우저: 최신 Chrome / Edge / Safari.

---

## 2.5 외부 네트워크에서 접속

사무실 밖(현장 부스, 모바일, 다른 기관)에서 접속하려면 **Cloudflare 빠른 터널**로 공개 주소를 발급합니다.
별도 계정·도메인이 필요 없으며, **원클릭 실행 스크립트** 하나로 서버 기동과 터널 생성이 함께 처리됩니다.

### 원클릭 실행 (권장)

프로젝트 폴더에서:

```bash
./start.sh          # 개발 서버 + Cloudflare 터널 (기본)
./start.sh prod     # 프로덕션 빌드본 + 터널 (시연·배포용, 더 안정적)
./start.sh local    # 터널 없이 사내망/LAN 에서만
```

실행하면 다음과 같이 **공개 주소**가 출력됩니다. 이 주소를 참여자·기업에 공유하세요.

```
🚀 배포 완료! 아래 주소를 공유하세요
  공개 주소 : https://<무작위>.trycloudflare.com
  로컬 주소 : http://localhost:5176
```

- 종료하려면 실행 중인 터미널에서 **Ctrl + C** 를 누릅니다(서버·터널이 함께 정리됩니다).
- ⚠️ 빠른 터널 주소는 **실행할 때마다 바뀝니다.** 고정 주소가 필요하면 사업단에서 정식 도메인 터널을 설정하세요.

> 스크립트는 처음 실행 시 `cloudflared`(터널 도구)와 의존성을 자동으로 설치하고,
> 다른 프로그램이 포트를 쓰고 있어도 **빈 포트를 자동 감지**해 안전하게 띄웁니다.
