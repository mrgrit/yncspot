# 05. 관리자 · 데이터 관리

[← 매뉴얼 홈으로](README.md)

> 대상: **시스템 관리자** · 진입 경로: `/admin`
> 관리자는 운영자의 모든 기능에 더해, **실데이터의 입력·수정·가져오기·내보내기**, **계정·권한 관리**,
> **감사 로그·백업**을 담당합니다. 이 문서는 시스템의 데이터가 정확하고 안전하게 유지되도록 돕습니다.

---

## 5.1 데이터 관리 콘솔 개요

관리자 화면(`/admin`)의 각 운영 메뉴는 **조회 + 데이터 편집**을 함께 제공합니다.
목록 상단의 **[등록]**, 행의 **[수정]/[삭제]**, 그리고 **[가져오기]/[내보내기]** 버튼으로 데이터를 직접 관리합니다.

### 관리 대상 데이터(엔티티) 한눈에

| 그룹 | 엔티티 | 관리 화면 |
|---|---|---|
| 사람 | 참여자(User) | `/admin/members` |
| 사람 | 강사(Instructor) · 멘토(Mentor) | 교육/멘토링 관리 |
| 발주 | 발주처(Employer) | Spot 운영 |
| 교육 | 프로그램(Program) · 과정(Course) · 수강(Enrollment) | `/admin/courses` |
| 일감 | Spot 일감(SpotJob) · AI 일자리(AiTask) | `/admin/spot-jobs` |
| 취업 | 협약기업(Company) · 채용공고(JobPosting) · 취업매칭(Placement) | `/admin/companies`, `/admin/placements` |
| 성과 | 배지(Badge) · 포트폴리오(Portfolio) | 자동 생성 + 관리 |
| 상담 | 상담(Counseling) | `/admin/members` |
| 시스템 | 알림(Notification) · AI 상담(ChatSession) | 자동 생성 |

> 전체 필드 정의는 **[07. 참고 자료 — 데이터 모델](07-참고자료-데이터모델·용어집.md)** 을 참조하세요.

---

## 5.2 데이터 입력 방식 3가지

### ① 개별 등록 (폼 입력)

- 각 관리 화면의 **[등록]** 버튼 → 입력 폼 → 저장.
- 필수값 미입력·형식 오류는 저장 전 **인라인 검증**으로 표시됩니다.
- 참조 항목(예: 과정의 담당 강사, Spot의 발주처)은 **드롭다운 선택**으로 연결해 무결성을 보장합니다.

### ② 일괄 가져오기 (CSV / 엑셀)

대량 데이터는 템플릿 파일로 한 번에 등록합니다.

1. 관리 화면에서 **[가져오기]** → **[템플릿 내려받기]** 로 표준 양식(.csv/.xlsx)을 받습니다.
2. 양식에 맞춰 데이터를 채웁니다(첫 행은 헤더, 코드값은 정해진 값 사용).
3. 파일을 업로드하면 **미리보기 + 검증 결과**가 표시됩니다.
   - ✅ 통과 행 / ⚠️ 경고 행(수정 후 진행) / ❌ 오류 행(제외)
4. **[가져오기 확정]** 을 누르면 통과 행만 등록됩니다. 오류 리포트는 내려받아 수정 후 재시도합니다.

**검증 규칙 예시**

- 필수 컬럼 누락·빈값 → 오류
- 코드값 오타(예: 트랙은 `try_job`/`get_job` 만 허용) → 오류
- 참조 대상 없음(예: 존재하지 않는 발주처 ID) → 오류
- 중복 키(이미 등록된 이메일 등) → 경고(건너뛰기/덮어쓰기 선택)
- 날짜·숫자 형식 불일치 → 오류

### ③ 외부 연동 (선택)

- 정부 플랫폼 연계 필드(예: 통합플랫폼 등재, 고용24 구직준비도 검사·점수)는
  연동 또는 일괄 업로드로 갱신합니다. 참여자 상세에서 개별 갱신도 가능합니다.

---

## 5.3 엔티티별 입력 가이드(요약)

각 엔티티의 **필수 필드**와 **주의점**입니다. 전체 필드는 [07. 데이터 모델](07-참고자료-데이터모델·용어집.md) 참조.

### 참여자(User)

- 필수: 이름, 연락처, 트랙(`try_job`/`get_job`), 상태, 소속/전공, 목표 직무
- 자동: 등급·누적 Spot·누적 보상은 **활동 실적으로 자동 계산**(직접 입력 금지)
- 민감: 상황·사연·신청 계기·`쉬었음` 여부는 개인정보 — 접근 통제 대상

### 강사(Instructor) / 멘토(Mentor)

- 강사: 이름·전문분야·소개 → 과정의 담당 강사로 연결
- 멘토: 이름·소속기업·직책·전문영역 → 멘토링 기록에 연결

### 발주처(Employer)

- 이름·카테고리(카페/매장/행사대행/물류/데이터입력 등)·지역·담당자·**평점**
- 평점은 Spot **매칭 점수**에 반영되므로 실제 평가로 유지

### 프로그램(Program) / 과정(Course) / 수강(Enrollment)

- 프로그램: 트랙·영역·난이도·유형·시수·정원·기간·**커리큘럼**·**학습성과**
- 과정: 소속 프로그램·담당 강사·형태·장소·일정·정원
- 수강: 참여자·과정·**출석률·성적·상태** → 출석 80%↑ & 성적 60↑ 시 이수·배지 자동

### Spot 일감(SpotJob) / AI 일자리(AiTask)

- 일반: 발주처·제목·설명·카테고리·소요시간·기준 일당·요구 등급·지역·일정
- AI 일자리: 도메인·**검수 가이드**·**출력 폼 필드**(종류·라벨·필수 여부·선택지)·예상시간·건당 보상

### 협약기업(Company) / 채용공고(JobPosting) / 취업매칭(Placement)

- 기업: 이름·업종·규모·주소·매칭 학과·채용 정원·담당자
- 공고: 소속 기업·제목·업무·자격요건·계약형태·복리후생·마감일
- 취업매칭: 참여자·기업·공고·단계(지원→면접→채용/불합격). **채용 확정이 취업의 단일 기준**

### 상담(Counseling)

- 참여자·유형(초기/정기/진로/심리/취업)·상담일·상담자·요약·메모·다음 계획
- 운영자 매뉴얼 [4.2](04-운영자-매뉴얼.md#42-참여자-관리--adminmembers) 의 상담 등록 절차와 동일

## 5.4 계정 · 권한 관리

### 계정 발급

- **[계정 관리]** 에서 사용자 계정을 발급하고 **역할**을 부여합니다.
  - `youth`(참여자) · `operator`(운영자) · `company`(협약기업) · `admin`(관리자)
- 협약기업 계정은 특정 기업(Company)에 연결되어, 그 기업의 포털만 사용합니다.
- 계정 비활성화·비밀번호 초기화·역할 변경을 지원합니다.

### 접근 통제 원칙(중요)

| 데이터 | youth | operator | admin | company |
|---|:---:|:---:|:---:|:---:|
| 본인 활동(Spot·학습·포트폴리오) | ✅(본인) | ✅ | ✅ | ❌ |
| 상담·사연·신청 계기 | ✅(본인) | ✅ | ✅ | ❌ **비공개** |
| 수료생 직무 프로필(역량·이수·캡스톤·배지) | ✅(본인) | ✅ | ✅ | ✅ |
| 데이터 입력·계정·권한 | ❌ | 일부 | ✅ | ❌ |

> 🔒 협약기업은 인재풀에서 **직무 프로필만** 봅니다. 상담·사연·연락처 등 개인정보는 시스템 차원에서 차단됩니다.

---

## 5.5 감사 로그 · 변경 이력

- 데이터의 **생성·수정·삭제**와 **가져오기/내보내기**, **로그인·권한 변경**이 감사 로그에 기록됩니다.
- 각 기록: 시각·수행자(계정)·대상 데이터·변경 전/후 값.
- 민감 정보(상담·사연) 열람 이력도 남겨, 개인정보 보호 책임성을 확보합니다.
- 잘못된 변경은 이력을 근거로 **되돌리기(복원)** 할 수 있습니다.

---

## 5.6 백업 · 내보내기

- **자동 백업**: 전체 데이터가 주기적으로 백업됩니다.
- **수동 내보내기**: 각 화면의 **[내보내기]** 로 현재 목록을 CSV/엑셀로 저장합니다(보고·감사용).
- **전체 스냅샷**: 관리자 콘솔에서 전체 데이터셋을 백업/복원할 수 있습니다.
- 개인정보가 포함된 내보내기 파일은 **암호·접근 제한** 후 취급하세요.

---

## 5.7 데모 데이터에서 실데이터로 전환

시연·검증 단계에서 사용한 가상 데이터를 실데이터로 교체하는 절차입니다.

1. **초기화**: 관리자 콘솔에서 데모 데이터셋을 **비웁니다**(백업 후 진행).
2. **기준 데이터 먼저**: 발주처·강사·멘토·프로그램/과정·협약기업 등 **참조 대상**을 먼저 등록합니다.
3. **사람 데이터**: 참여자를 CSV로 일괄 등록합니다.
4. **활동 데이터**: 수강·Spot 이력·취업매칭·상담을 등록/연동합니다.
5. **검증**: 대시보드·보고서 수치가 기대와 맞는지 확인합니다(지표는 자동 집계).

> ⚠️ **순서 중요** — 참조 대상(발주처·강사·기업 등)이 없으면 하위 데이터(일감·과정·공고) 등록 시 오류가 납니다.
> 반드시 **기준 데이터 → 사람 → 활동** 순으로 입력하세요.

### 데이터 무결성 규칙(요약)

- 모든 참조는 **존재하는 대상**을 가리켜야 합니다(강사·발주처·기업·프로그램 등).
- **취업 상태**는 취업매칭의 `hired` 로만 확정됩니다(수기 변경 금지).
- **등급·보상·배지**는 규칙에 따라 자동 산출됩니다(직접 값 주입 금지).

## 관리자 체크리스트

| 주기 | 할 일 |
|---|---|
| 최초 | 데모→실데이터 전환(기준→사람→활동 순) |
| 수시 | 계정 발급·역할 관리, 참여자/기업 가져오기 |
| 주간 | 데이터 검증(대시보드·보고서 대조) |
| 주간 | 백업 상태 점검, 필요한 내보내기 |
| 월간 | 감사 로그 검토, 권한 재점검 |
