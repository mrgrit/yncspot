# 03. 참여자 매뉴얼

[← 매뉴얼 홈으로](README.md)

> 대상: **부트캠프 참여 청년** · 진입 경로: `/me`
> 참여자는 본인의 활동만 보고 관리합니다. 다른 참여자의 정보는 볼 수 없습니다.

---

## 3.1 마이페이지(홈) — `/me`

로그인 후 처음 만나는 나의 대시보드입니다.

- **내 프로필 요약**: 이름·트랙·소속/전공·목표 직무·한 줄 소개
- **Spot 등급 & 진행도**: 현재 등급(🥉🥈🥇💎)과 다음 등급까지 남은 횟수·평점
- **누적 보상**: 지금까지 받은 Spot 보상 합계
- **내 상황(페르소나)**: 현재 상황과 신청 계기 — *본인에게만 보입니다*
- **상담 내역**: 사업단과 진행한 상담 기록(초기·정기·진로·심리·취업) — *본인·사업단만 열람*
- **추천 활동**: 지금 신청하기 좋은 Spot·과정·채용 바로가기

> 🔒 상황·사연·상담은 **나와 사업단만** 볼 수 있습니다. 협약기업에는 공개되지 않습니다.

---

## 3.2 Spot Work — `/spot`

부담 없이 시작하는 **단기 일감** 게시판입니다. 두 종류가 함께 노출됩니다.

1. **일반 Spot** — 카페·매장·행사대행·물류·데이터입력 등 대구 남구 권역 단기 일감
2. **AI 일자리** — AI가 만든 결과물을 사람이 검수하는 온라인 크라우드워크 → [3.3](#33-ai-일자리-검수-작업)

### 게시판에서 하는 일

- **필터**: 카테고리(일반/AI 일자리), 요구 등급, 지역, 보상 등으로 좁혀 보기
- **매칭 점수**: 각 일감에 나와의 **적합도 점수(최대 100)** 가 표시됩니다.
  - 내 등급, 관심사 일치, 거리, 재수행 발주처, 발주처 평점을 종합해 계산됩니다.
- 제목을 클릭하면 **상세**(`/spot/:id`)로 이동합니다.

### Spot 상세 & 신청 — `/spot/:id`

- 일감 설명·소요 시간·기준 일당(또는 건당 보상)·요구 등급·일정 확인
- **신청하기** 버튼으로 지원합니다. 신청하면 알림으로 진행 상황이 안내됩니다.
- **AI 일자리**인 경우 **작업 수행하기** 버튼이 나타나 검수 화면으로 이동합니다.

### 보상 안내

- 일반 Spot의 기준 일당은 **약 28,000 ~ 63,000원**, AI 검수는 **건당 12,000 ~ 28,000원**입니다.
- 개인의 첫 성공에는 단계별 보너스가 더해집니다: **1번째 교통비 · 2번째 ½일당 · 3번째 일당 전액**.

---

## 3.3 AI 일자리 (검수 작업) — `/spot/:id/work`

AI가 생성한 콘텐츠·에이전트 결과가 **정확하고 안전한지 사람이 확인**하는 온라인 일자리입니다.
장소 제약 없이, 짧은 시간에 수행할 수 있습니다.

### 화면 구성

- **좌측(고정)**: 검수 가이드 — 무엇을 어떤 기준으로 확인해야 하는지 단계별 안내
- **우측**: 출력 폼 — 작업에 따라 필요한 입력칸이 **동적으로** 나타납니다
  (짧은 글·긴 글·URL·평점·단일/다중 선택·예·아니오·스크린샷·명령 출력·JSON 등)

### 6개 검수 도메인

| 도메인 | 검수 대상 |
|---|---|
| 식음료 알레르기 라벨 | 알레르기 표기 정확성 |
| 복지 챗봇 응답 | 안내 정확성·안전성 |
| 보안 설정(nftables) | 방화벽 규칙 적정성 |
| 이미지 캡션 | 이미지 설명 정확성 |
| 사실 검증 | 주장·정보의 사실 여부 |
| 데이터 라벨링 | 라벨 품질 |

### 수행 절차

1. 가이드를 읽고 기준을 숙지합니다.
2. 우측 폼의 필수 항목을 모두 채웁니다.
3. **제출**하면 결과가 검토되어 **건당 보상**이 정산 이력에 반영됩니다.

---

## 3.4 Spot 이력 & 정산 — `/spot/history`

- 지금까지 수행한 Spot·AI 일자리의 **정산 내역**을 확인합니다.
- 각 건별: 수행 일시, 기준 보상, 보너스(교통비/½/전액), **총 지급액**, 받은 평점·피드백
- 누적 수행 횟수는 **등급 승급**에, 누적 지급액은 마이페이지 **누적 보상**에 반영됩니다.

---

## 3.5 학습(교육과정) — `/courses`

- 개설된 **교육 과정**을 둘러보고 **수강 신청**합니다.
- 과정은 영역(사회역량·교양·AI 공통·전공)과 난이도(공통·초급·중급·고급)로 구분됩니다.
- 과정 제목을 클릭하면 **커리큘럼(모듈/주차)·학습 성과·개설 분반(강사·일정)** 을 볼 수 있습니다.
- 신청한 과정은 **수강 중** 상태로 등록되며, 출석·성적이 쌓입니다.

> 🎓 **배지 자동 발급** — 출석률 **80% 이상**이고 성적 **60점 이상**이면 이수로 인정되어
> 디지털 배지가 자동 발급됩니다(점수 구간에 따라 배지 등급 결정).

---

## 3.6 채용 — `/jobs`

- 협약기업의 **채용 공고**를 확인하고 지원합니다.
- 공고 상세(`/jobs/:id`)에서 담당 업무·자격 요건·근무 조건·계약 형태(협약채용/유보채용/일반)를 확인합니다.
- **지원하기**로 지원하면 **취업매칭** 절차(지원 → 면접 → 채용)가 시작되고 알림으로 안내됩니다.

---

## 3.7 포트폴리오 — `/me/portfolio`

교육·활동의 결과물을 모아 **나를 소개하는 포트폴리오**입니다.

- **캡스톤 산출물**과 **실습 결과물**이 구분 표시됩니다.
- **배운 것(학습)** 이 칩 형태로 정리됩니다.
- 프로젝트 제목을 클릭하면 **개요·담당 역할·사용 기술·성과·산출물 링크** 상세가 열립니다.
- **공유 카드**로 정리해 협약기업에 노출할 수 있습니다(직무 프로필만 공개, 상담·사연 비공개).

> 수료(이수완료/취업) 후에도 포트폴리오는 **보존**되어 사후관리와 재취업에 활용됩니다.

---

## 3.8 배지 — `/me/badges`

- 획득한 **디지털 배지**를 모아 봅니다(과정 이수·Spot 마일스톤·캡스톤·멘토링·트랙 전환 등).
- 각 배지는 등급(🥉🥈🥇💎)과 발급일, **인증 URL**을 가집니다.
- 배지는 포트폴리오와 채용 지원 시 역량 근거로 활용됩니다.

---

## 3.9 AI 상담 — `/chat`

- 진로·학습·Spot 관련 궁금증을 **AI 어시스턴트**에게 물어볼 수 있습니다.
- 내 트랙·관심사·활동 맥락을 반영해 답변합니다.
- 상단 **「API 키」** 에서 Anthropic API 키를 입력하면 실제 Claude 응답을 사용합니다.
  - 키가 없거나 호출이 실패해도 **규칙 기반 오프라인 응답**으로 항상 작동합니다.
  - 키는 브라우저에만 저장되며 서버로 전송되지 않습니다.

---

## 자주 하는 일 빠른 안내

| 하고 싶은 것 | 어디서 |
|---|---|
| 오늘 할 수 있는 일감 찾기 | `/spot` → 매칭 점수 높은 순 |
| 온라인으로 짧게 벌기 | `/spot` → **AI 일자리** 필터 |
| 얼마 받았는지 확인 | `/spot/history` |
| 과정 신청 | `/courses` |
| 취업 지원 | `/jobs` |
| 내 포트폴리오 정리 | `/me/portfolio` |
| 진로 상담(AI) | `/chat` |
