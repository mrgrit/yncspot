## 🚀 30초 요약

- **도약**은 부담 없는 **Spot Work(단기 일감 + AI 검수 크라우드워크)** 로 청년을 유입시켜,
  **등급·보상 → 3영역 교육 동시이수 → 포트폴리오 → 협약기업 취업 → 수료생 사후관리**까지
  하나의 흐름으로 연결하는 플랫폼입니다.
- 4개 역할이 각자의 전용 화면을 사용합니다.
  **참여자**(`/me`) · **사업단 운영자**(`/admin`) · **협약기업**(`/company`) · **시스템 관리자**(`/admin`).
- 모든 지표(취업률·양성인원·만족도 등)는 입력된 실데이터에서 **실시간으로 자동 집계**됩니다.
- 참여자의 **상담 내역·사연** 등 민감 정보는 **사업단·본인만** 열람할 수 있도록 접근이 통제됩니다.
